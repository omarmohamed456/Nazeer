# Geology matching table

`tiles_wide.csv` is the 10° geology table used by the Earth-analog matcher.

## Provenance

The table was generated by the project owner for Planet Explorer. The source
rasters/vectors used to derive it are not included in this repository. If you
plan to redistribute the table or the app, confirm the terms of the underlying
source data first.

## Grid

- 18 rows × 36 columns = 648 cells
- Cell size: 10° × 10°
- `r00` is the southernmost row (`-90°` to `-80°` latitude); `r17` is the
  northernmost row (`80°` to `90°`)
- `c00` is the westernmost column (`-180°` to `-170°` longitude); `c35` is the
  easternmost column (`170°` to `180°`)
- `tile_id` is `rXXcYY`

The dataset row order is **south-to-north**, while NASA Trek map tile rows run
north-to-south. The backend keeps those conventions separate.

## Main columns

The joined table contains Moon, Mars, and Earth columns for the same 10° cell.
The app uses:

- Moon: `moon_frac_highlands`, `moon_frac_impact`, `moon_frac_plains`,
  `moon_frac_volcanic`, `moon_mapped_frac`, Moon age fractions
- Mars: `mars_frac_ice`, `mars_frac_impact`,
  `mars_frac_surficial_unconsolidated`, `mars_frac_undivided_terrain`,
  `mars_frac_volcanic`, `mars_mapped_frac`, Mars age fractions and mean ages
- Earth: `earth_mapped_class_frac_*`, `earth_mapped_frac`,
  `earth_dominant_class`

`earth_mapped_class_frac_*` is used for matching because it is normalized over
mapped area. Some `earth_mapped_frac` values exceed 1; the app clamps coverage
to 1 for scoring and display.

## Matching crosswalk

Direct classes:

- volcanic → volcanic
- ice → ice
- Mars surficial_unconsolidated → Earth surficial_unconsolidated

Heuristic classes:

- Moon highlands → Earth plutonic + metamorphic ("crystalline")
- Moon plains → Earth sedimentary ("lowland/sedimentary")

No Earth equivalent:

- impact
- Mars undivided_terrain

The unmatched classes are not forced onto an Earth class. They reduce the
shared-area mass and therefore the confidence score.

## Known limitations

- Earth coverage is land-only: 238 cells have zero mapped area, 201 have at
  least 50% coverage, and 156 have at least 80%.
- Earth has no impact, highlands, plains, or undivided-terrain classes in this
  table, and no Earth age data.
- Moon and Mars are fully mapped; Earth is not.
- The 10° cell is much coarser than the NASA Trek imagery tiles. A map tile can
  overlap several dataset cells.
- The crosswalk is a transparent heuristic, not a geologic provenance model.
